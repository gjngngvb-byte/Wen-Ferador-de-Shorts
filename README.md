# NoAdsDL → WenClips Bridge

Serviço separado que automatiza o fluxo do NoAdsDL e envia o vídeo baixado ao processamento do WenClips.

Deploy Docker no Render. O serviço usa Playwright/Chromium, ffprobe e a API de upload do WenClips Engine.

**Importante:** o site NoAdsDL pode mudar o HTML ou bloquear automação. O deploy precisa passar por teste real do fluxo antes de ser considerado operacional. Use somente vídeos que você tem autorização para baixar e reutilizar.
